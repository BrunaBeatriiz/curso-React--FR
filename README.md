## 🇧🇷 Sobre o Projeto

Aplicação de gerenciamento de tarefas desenvolvida com React, com foco em organização, produtividade e uma interface moderna.

O usuário pode adicionar tarefas com título e descrição, marcar como concluídas e remover tarefas de forma simples e intuitiva.

---

## 🇺🇸 About the Project

A task management application built with React, focused on organization, productivity, and a modern user interface.

Users can add tasks with title and description, mark them as completed, and remove tasks easily.

---

## 🚀 Tecnologias | Technologies

<p align="center">
  <img src="https://skillicons.dev/icons?i=react,js,tailwind" />
</p>

* React
* JavaScript
* Tailwind CSS

---

## 🎯 Funcionalidades | Features

✔️ Adicionar tarefas
✔️ Adicionar descrição às tarefas
✔️ Marcar como concluída
✔️ Excluir tarefa individual
✔️ Excluir todas as tarefas
✔️ Interface moderna e responsiva

---

## 💻 Como executar | How to run

```bash
# Clone o repositório
git clone https://github.com/BrunaBeatriiz/task-manager-react.git

# Acesse a pasta
cd task-manager-react

# Instale as dependências
npm install

# Execute o projeto
npm run dev
```
